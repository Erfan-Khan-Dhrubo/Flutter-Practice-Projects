# VangtiChai

## Purpose

VangtiChai is a simple Android app built for CSE 489 Assignment 1.
The user enters a money amount with a numeric keypad, and the app shows how that amount can be made using Bangladeshi Taka notes.

## Technologies used

* Flutter
* Dart
* Material Design
* Simple `StatefulWidget` + `setState()`

## How to run the project

1. Make sure Flutter is installed (`flutter doctor`).
2. Open this project folder in your IDE (Android Studio / VS Code).
3. Connect an Android emulator or a physical device.
4. From the project root, run:

```bash
flutter pub get
flutter run
```


## Tested screen sizes / devices

Assignment target devices:

* Pixel XL (about `411 x 731` dp) — Portrait and Landscape
* Nexus 10 (about `800 x 1280` dp) — Portrait and Landscape
